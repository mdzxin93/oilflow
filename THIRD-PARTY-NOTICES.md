# Third-party software

Runtime libraries include Express (MIT), MongoDB Node.js Driver (Apache-2.0), express-session (MIT), connect-mongo (MIT), Helmet (MIT), express-rate-limit (MIT), Zod (MIT), web-push (MIT), PDFKit (MIT), dotenv (BSD-2-Clause), fflate (MIT) and mongodb-memory-server-core (MIT). Development libraries include Vite (MIT), Supertest (MIT) and JSDOM (MIT). Exact versions and transitive dependencies are pinned in package-lock.json; published packages retain their own copyright/license notices.

MongoDB server is downloaded separately from MongoDB's official download service and is subject to MongoDB's own distribution/license terms (SSPL/community terms as applicable). The ZIP does not redistribute the MongoDB binary. The database manager runs a real persistent mongod; its library name does not mean the business data is stored only in RAM.

No remote font, analytics tracker, paid AI API or APK signing secret is included.
